# 🚗 Autoescuela Mega (Torrent, Valencia)

Sitio web oficial y landing page institucional de **Autoescuela Mega** en Torrent (Valencia), centro oficial de formación vial de conductores y transportistas profesionales.

---

## 🌟 Características Principales

* **Permisos de Conducción Particulares:** Permiso B (Coche), Permisos de Moto (AM, A1, A2, Carnet A) y Permiso B+E.
* **Formación Profesional de Transporte:** Camión Rígido (C), Tráiler Articulado (C+E) y Autobús (D).
* **Cursos CAP (Certificado de Aptitud Profesional):** Renovación continua intensiva de 35h exclusivamente los sábados (07:00 a 14:30 h) y CAP Inicial (140h).
* **Recuperación de Puntos DGT:** Centro oficial homologado para cursos de recuperación parcial (12h - hasta 4 puntos) y pérdida de vigencia (24h).
* **Prevención de Riesgos y Maquinaria:** Plataformas elevadoras móviles (PEMP norma UNE-EN 280), Carretillas elevadoras y Puente Grúa.
* **100% Bonificable por FUNDAE:** Gestión telemática integral para empresas y trabajadores en activo a coste 0 €.

## 🛠️ Tecnologías y Arquitectura

* **Frontend:** HTML5 Semántico, CSS3 Moderno (Custom Properties, Flexbox, CSS Grid) y Vanilla JavaScript ultra-rápido.
* **Diseño y UX:** Sistema de diseño responsive con modo claro, animaciones fluidas, accesibilidad y componentes interactivos (Slider de reseñas, Showcase de permisos con scroll sync, Acordeón Alloy y Modal dinámico).
* **Optimización y Performance:** Imágenes en formato WebP de alta compresión, carga diferida (`loading="lazy"`), scripts no bloqueantes y fondo fluido con canvas WebGL inteligente (`assets/wave-gradient.js`) con pausa por IntersectionObserver.
* **Seguridad y Despliegue:** Configuración lista para Vercel (`vercel.json`) con cabeceras de seguridad HTTP (X-Content-Type-Options, X-Frame-Options, Referrer-Policy) y cache inmutable para assets estáticos.

## 🚀 Despliegue en Vercel

El proyecto está preparado para despliegue automático continuo con un clic conectando este repositorio de GitHub a [Vercel](https://vercel.com):

1. Importar el repositorio `ahk2001/autoescuelamega` en el panel de Vercel.
2. Seleccionar el framework preset como **Other** (HTML estático).
3. Hacer clic en **Deploy**.
